# Food Delivery Admin Web

## Overview
A web-based administrative dashboard used by system administrators to oversee the platform's operations, users, and performance.

## Tech Stack
- **Framework**: React.js
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM
- **Icons**: Lucide React, React Icons, Heroicons
- **Charts**: Recharts (for analytics and dashboards)

## Features
- **Dashboard**: Visual analytics using Recharts.
- **User Management**: Likely includes interfaces to manage users, approver drivers/restaurants.
- **Toast Notifications**: `react-toastify`.

## Scripts
- `dev`: Start Vite development server.
- `build`: Build for production.
