# Food App Client

## Overview
The main mobile application for customers to browse restaurants, view menus, and place food orders.

## Tech Stack
- **Framework**: Expo / React Native
- **Router**: Expo Router
- **Payments**: Stripe (`@stripe/stripe-react-native`)
- **Maps**: `expo-location`, `react-native-maps`
- **UI**: `react-native-paper`, `lottie-react-native`
- **Storage**: `@react-native-async-storage/async-storage`

## Features
- **Browsing**: View restaurants and menus.
- **Ordering**: Cart management and checkout flow.
- **Payments**: Integrated Stripe payments.
- **Tracking**: Order status tracking.
- **Cross-Platform**: Support for Android and iOS.

## Scripts
- `start`: Start Expo development server.
- `android` / `ios`: Launch on simulators/devices.
