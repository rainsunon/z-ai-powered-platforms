# Client Delivery App

## Overview
A mobile application for delivery drivers, built with React Native and Expo. It allows drivers to receive and manage delivery requests.

## Tech Stack
- **Framework**: Expo / React Native
- **Router**: Expo Router (File-based routing)
- **Maps**: `react-native-maps`
- **Real-time**: `socket.io-client`
- **Backend Integration**: `axios`, `firebase`
- **UI Components**: `react-native-paper`, `react-native-vector-icons`

## Features
- **Order Acceptance**: Drivers can view and accept delivery jobs.
- **Navigation**: Map integration for delivery routing.
- **Real-time Updates**: Socket.io integration for order status and tracking.
- **Cross-Platform**: Support for Android and iOS.

## Scripts
- `start`: Start Expo development server.
- `android` / `ios`: Launch on specific simulators/devices.
- `web`: Run usage for web (though primarily mobile).
