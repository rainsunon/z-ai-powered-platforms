# Restaurant Web Portal

## Overview
A web portal for restaurant owners and managers to handle their menus, orders, and store settings.

## Tech Stack
- **Framework**: React.js
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Forms**: React Hook Form with Zod validation.
- **Maps**: `@react-google-maps/api`
- **Integration**: Firebase, Lottie React (animations).

## Features
- **Order Management**: Interface to view and update incoming orders.
- **Menu Management**: Forms to add/edit menu items.
- **Location**: Google Maps integration for restaurant location setup.

## Scripts
- `dev`: Start Vite development server.
- `build`: Build for production.
